# MX Float CUDA FP6 and FP8

This project provides a user interface to a the CUDA C++ library that implements software conversion between 32-bit float (FP32) and a custom 8 and 6-bit floating point format

## Build

```
mkdir -p build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j
```

## Run example

run this to see a manual:
./convert
